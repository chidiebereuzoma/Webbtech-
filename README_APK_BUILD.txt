WEBBTECH POWERBANK RENTAL — APK READY V2

FASTEST WAY TO GET THE APK (NO ANDROID STUDIO REQUIRED)
1. Create a free GitHub repository.
2. Upload the entire contents of this project to the repository.
3. Open the Actions tab.
4. Select "Build WEBBTECH APK".
5. Click "Run workflow".
6. When the workflow finishes, open the completed run.
7. Download the artifact named "WEBBTECH-Rental-debug-apk".
8. Extract it and install app-debug.apk on Android.

ANDROID STUDIO METHOD
1. Open this folder in Android Studio.
2. Let Android Studio sync the Gradle project.
3. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
4. The debug APK will be in:
   app/build/outputs/apk/debug/app-debug.apk

APP DETAILS
- Package: com.webbtech.rental (debug build uses com.webbtech.rental.debug)
- App name: WEBBTECH Rental
- Portrait Android app
- V2 web app bundled locally inside the APK
- PB001-PB100 and their QR codes included
- Customer address, ID number, collateral
- Rental fee entered per transaction; no fixed fee
- 24-hour expiry
- First overdue period: 50% of that rental's fee
- Each additional 24-hour period: 100% of that rental's fee

IMPORTANT
The prototype stores data locally on the device. It is not yet a multi-phone/cloud system.
The exact WEBBTECH logo should replace the included wordmark placeholder when you provide the original logo file.
